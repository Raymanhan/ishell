# iShell

[![Build installers](https://github.com/Raymanhan/ishell/actions/workflows/release.yml/badge.svg)](https://github.com/Raymanhan/ishell/actions/workflows/release.yml)
[![Release](https://img.shields.io/github/v/release/Raymanhan/ishell?label=release)](https://github.com/Raymanhan/ishell/releases/latest)
[![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

iShell 是一个基于 Tauri + React + Rust 的轻量级 SSH 桌面工作台，用来在一个紧凑界面里管理远程服务器。它集成了服务器资料、交互式终端、SFTP 文件操作、小文件远程编辑、命令历史、主机实时监控和玻璃质感桌面界面。

**语言**：[English](README.md) | 简体中文

## 功能亮点

- **SSH 连接管理**：以文件夹树组织连接，支持搜索、标签、备注和主机颜色。
- **连接顺序持久化**：连接排序和所在分组会保存到本地数据库，重启后保持不变。
- **安全保存密钥信息**：密码通过操作系统钥匙串/Secret Store 保存，不会明文写入导出的连接文件。
- **导入/导出连接**：可导出选中的主机或文件夹为 JSON/ZIP，也可选择用口令加密导出密码。
- **交互式终端**：基于 xterm 的真实 PTY 会话，支持重连、复制标签页、标签排序、跨窗口交接、命令历史和终端内搜索。
- **分屏与广播输入**：一个标签最多分成 4 个窗格，可左右、上下嵌套分屏；广播输入可把键入内容同步发送到多个会话。
- **命令片段**：保存常用命令，一键发送或执行，广播开启时可同时发到多台服务器。
- **跳板机**：服务器可经由另一台已保存的服务器连接，支持多级串联，每一级使用各自的账号和密码或私钥。
- **端口转发**：按服务器管理本地（-L）、远程（-R）和 SOCKS5 动态（-D）转发，后台运行并显示实时状态。
- **OpenSSH 与 russh 双后端**：macOS/Linux 使用系统 OpenSSH；Windows 使用纯 Rust `russh` 后端和连接池。
- **SFTP 文件浏览器**：支持树形/多列视图、上传、下载、新建文件夹、重命名、删除、右键菜单、软链接识别、终端目录跳转、小文件远程编辑和独立日志滚动查看。
- **实时主机监控**：展示 CPU、GPU、显存、内存、Swap、磁盘、负载、进程排行和网络吞吐，并支持一键复制主机/IP。
- **多主题玻璃桌面界面**：透明原生窗口、9 套主题（含 Otty 风格与 Claude Code 风格的浮动卡片主题）、透明终端背景和平台字体优化。

## 快速开始

1. 打开 [Releases](https://github.com/Raymanhan/ishell/releases/latest)，下载适合当前系统的安装包。
2. 安装并启动 iShell。
3. 点击顶部栏的连接管理入口。
4. 如有需要先创建文件夹，然后添加服务器。
5. 选择密码或 SSH Key 认证方式并保存。
6. 双击服务器，或通过右键菜单连接，打开终端标签页。
7. 通过顶部栏打开 SFTP、实时监控、命令历史、设置或连接管理面板。

## 使用手册

### 连接管理

- 在连接管理面板中搜索、选择、分组、编辑、导入、导出和删除服务器资料。
- 右键服务器可以连接、复制、重命名、编辑、导出或删除。
- 右键文件夹或空白区域可以重命名文件夹、新建文件夹、添加服务器、导入或导出。
- 可多选后执行批量导出或删除。
- 连接会保存 `sortOrder`，列表顺序和分组位置会在重启后保持稳定。
- 分组内连接会按保存顺序排序，顺序相同再按名称自然排序，浏览更可预期。

### 服务器资料

每个服务器资料包含：

- 名称、主机、端口、用户名、分组、标签、颜色和备注
- 认证方式：密码或私钥
- 可选私钥路径
- 可选跳板机：选择另一台已保存的服务器，先连上它再连到目标；跳板机自己也可以设置跳板机（最多 3 层）
- 保存前可直接测试连接
- 编辑密码时支持显示/隐藏切换

密码和连接资料分开保存。导出连接时，是否导出密码由用户决定；如果导出密码，可以设置口令进行加密保护。

### 终端标签页

- 每台已连接主机会打开一个终端标签页。
- 标签页支持激活、关闭、复制、重连和拖动排序。
- 标签页可以拖出并交接到另一个 iShell 窗口。
- 关闭原生窗口时会先关闭终端标签并隐藏应用，避免后台会话残留。
- 右键标签页可以打开标签级操作菜单。
- 顶部栏可设置为常驻显示，或在鼠标离开后自动隐藏、移到窗口顶端时再显示。
- 终端字号可在设置中调整。
- 命令历史支持搜索，并可将历史命令粘贴回当前终端。
- 在终端中按 `⌘F`（macOS）或 `Ctrl+Shift+F`（Windows/Linux）搜索输出，支持区分大小写、全字匹配和正则。

### 分屏与广播输入

- 右键标签选择“向右分屏”或“向下分屏”，或在终端中按 `⌘D` / `⇧⌘D`（macOS）、`Ctrl+Shift+D` / `Ctrl+Shift+E`（Windows/Linux）。新窗格连接同一台服务器。
- 在连接管理中右键服务器选择“分屏连接”，可在当前窗格旁打开另一台服务器。
- 分屏可以嵌套，一个标签最多 4 个窗格；拖动窗格之间的分隔线调整大小，点击窗格切换焦点，文件面板和监控面板跟随当前窗格。
- 点击顶部栏的广播按钮开启广播输入：在任一所选会话中键入的内容会同步发送到其他所选会话。默认选择当前标签的全部窗格（未分屏时为全部会话），可在终端下方的广播栏中逐个勾选。

### 命令片段

- 在顶部栏打开“命令片段”面板，保存常用命令，可填写名称和说明。
- 每个片段可设为“立即执行”（发送后自动回车）或只输入到终端供修改；多行片段会逐行发送。
- 点击片段发送到当前窗格；广播开启时会发送到所有广播会话。
- 片段保存在本地数据库中。

### 端口转发

在顶部栏打开“端口转发”面板，为当前服务器添加转发规则：

- **本地（-L）**：访问本机的监听地址，等于从服务器访问目标地址，常用于连接只对服务器开放的数据库或后台。
- **远程（-R）**：服务器上的监听地址收到的连接会转到本机能访问的目标地址。
- **SOCKS（-D）**：在本机开一个 SOCKS5 代理，经服务器访问网络。

转发在后台独立运行，关闭标签不会停止，退出 iShell 时全部停止。面板中显示每条转发的实时状态，失败时显示原因；可勾选“连接终端时自动启动”。跳板机设置对端口转发同样有效。

### SFTP 文件管理

在当前终端标签页中打开文件面板后，可以浏览远程文件系统。

支持操作：

- 在树形详情视图和多列视图之间切换。
- 上传文件或文件夹到当前目录，支持拖放目录；远端存在同名文件夹时会先确认是否完整替换，替换不会合并，并会删除远端独有内容。
- 下载选中的文件；新加入的传输任务会显示在队列顶部，方便查看最新进度。
- 新建文件夹、重命名条目、删除一个或多个条目。
- 软链接会显示专用图标，删除确认会说明只删除链接本身。
- 可从 SFTP 右键菜单将当前终端跳转到选中的远程目录。
- 打开小型文本文件，在内置编辑器中修改并保存回远程主机。
- 对选中文件打开实时滚动查看窗口，持续跟随远端日志新增内容。
- 拖动选择文本超出编辑器左右边界时，会自动横向滚动并继续扩展选择范围。
- 使用路径栏直接跳转到指定目录。

远程文本编辑限制为小文件，避免在远程会话中加载超大文件导致界面卡顿。

### 实时日志滚动查看

- 在 SFTP 文件右键菜单中选择实时滚动查看，针对当前主机上的文件打开独立窗口。
- 查看窗口不会占用主工作台，适合跟随应用日志、部署日志或系统日志。
- 可设置初始加载的尾部行数，并在窗口内重新应用。
- 支持暂停跟随、回到底部继续跟随、清空当前输出和重新启动滚动查看。
- 窗口关闭时会停止对应的远端 tail 进程，避免后台任务残留。

### 实时监控

状态面板会通过 SSH 采样当前主机信息：

- CPU 使用率
- GPU 使用率和显存占用（远端主机暴露支持指标时）
- 内存和 Swap
- 磁盘挂载
- Load Average
- 进程数量
- CPU/内存占用 Top 5 进程排行
- 网络上传/下载速度
- 主机/IP 一键复制

### 设置

设置窗口左侧是分类菜单，右侧是该分类的设置项：

- **外观**
  - 主题：云雾白、暮霭紫、Claude 深色、Claude 浅色、石墨灰、午夜蓝、墨玉绿、曜石黑、象牙白
  - 窗口透明度：100% 为主题原本的玻璃效果，调低会减少窗口背后内容的透出，0% 为完全不透明
  - 顶部栏自动隐藏开关
- **终端**
  - 终端字号
  - 新建实时滚动查看窗口的默认加载行数
- **关于与更新**：查看当前版本、手动检查更新、自动检查更新（启动后及每 6 小时）

有新版本时，iShell 会弹出提示，可直接下载、校验并安装，完成后自动重启。Linux 上应用内更新适用于 AppImage；`.deb` 和 `.rpm` 安装请从 Release 页面下载新安装包。

所有主题都会在可用平台上启用 Tauri 原生窗口效果，并配合透明 xterm 背景，让终端和面板呈现统一的桌面玻璃质感。云雾白、暮霭紫和两套 Claude 主题会把终端、首页和停靠面板呈现为浮在毛玻璃底色上的圆角卡片；每套主题都带有独立的 16 色终端配色。

## 环境要求

- Node.js 22 或更高版本
- Rust stable 工具链
- 对应平台的 Tauri 系统依赖
- macOS 和 Linux 需要 OpenSSH
- Linux 运行时保存密码需要 Secret Service，例如 GNOME Keyring 或 KWallet。

Linux 下安装 Tauri 所需 WebKitGTK 和打包依赖：

```bash
sudo apt-get update
sudo apt-get install -y libwebkit2gtk-4.1-dev libayatana-appindicator3-dev librsvg2-dev patchelf libssl-dev
```

## 发布

推送 `v*` 标签后，GitHub Actions 会自动构建 Release。也可以在 GitHub Actions 页面手动运行 **Build installers** 工作流。

```bash
git tag v1.4.2
git push origin v1.4.2
```

发布工作流会构建 Windows、Linux、macOS Intel 和 macOS Apple Silicon 安装包，并把产物上传到 GitHub Release。

### 应用内更新

应用内更新会从最新的 GitHub Release 下载 `latest.json`，并且只安装用项目更新密钥签名过的更新包。公钥写在 `src-tauri/tauri.conf.json` 的 `plugins.updater.pubkey`；私钥保存在仓库的 Actions Secrets：

- `TAURI_SIGNING_PRIVATE_KEY`：私钥文件的内容
- `TAURI_SIGNING_PRIVATE_KEY_PASSWORD`：私钥密码

生成密钥对（在项目目录下运行，会提示设置密码）：

```bash
npm run tauri signer generate -- -w ~/.tauri/ishell.key
```

配置好后，发布工作流会为更新包签名（macOS 的 `.app.tar.gz`、Windows 的 NSIS 安装包、Linux 的 AppImage），并把 `latest.json` 和安装包一起发布。未配置时 Release 仍会正常构建，只是不包含更新包。请妥善保管私钥：换用其他密钥签名的版本会被已安装的应用拒绝。

## 项目结构

```text
src/
  api/              Tauri IPC 封装和运行环境检测
  components/       React UI 组件
  constants/        主题 token 和共享常量
  features/         按功能划分的 hooks 和工具：连接、分屏、传输队列、片段、端口转发、更新
  mocks/            浏览器预览用演示数据
  styles/           基础、布局、控件、视图和主题 CSS 模块
  utils/            格式化、高亮、拖动等工具
  App.tsx           工作台布局和标签、窗格编排

src-tauri/src/
  commands.rs       Tauri 命令边界
  models.rs         命令共享的可序列化 DTO
  openssh.rs        OpenSSH 参数、跳板机 ProxyCommand 和 askpass 辅助
  pool.rs           传输失效和连接池边界
  russh_transport.rs Windows 使用的纯 Rust SSH 传输（含跳板机和端口转发）
  ssh/              SSH 远程操作：命令执行、监控、SFTP、上传、下载
  store.rs          服务器、片段、端口转发的本地数据库和密钥加密
  tail_monitor.rs   远程文件实时滚动查看进程注册表
  terminal.rs       交互式终端会话注册表
  tunnel.rs         运行中的端口转发注册表
  time.rs           时间工具
  lib.rs            Tauri 应用组装
```
