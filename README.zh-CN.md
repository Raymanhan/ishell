# iShell

**带 AI 服务器助手的一站式 SSH 工作台。**

iShell 是一款面向开发者、运维工程师和自托管用户的开源 SSH 桌面工作台。连接服务器后，你可以在一个窗口里分屏操作多台主机、传输文件、修改配置、跟随日志并查看资源占用，减少在终端、文件工具和监控窗口之间来回切换。

内置 **AI 服务器助手**：用自然语言描述部署或排障目标，助手可以通过当前 SSH 连接执行命令、读写文件、编写并运行代码，并展示每一步的输出。你可以接入自己的 OpenAI 兼容模型服务，选择模型、思考程度和操作权限。

也可在远程项目中使用已安装的 Codex、Claude Code 等 AI CLI，用分屏把 **AI 会话、代码差异、测试与日志** 放在一起。

基于 **Tauri 2 + React 19 + Rust** 构建，提供 Windows、macOS 和 Linux 安装包，以 MIT 协议开源。

## 为什么选择 iShell

| 你正在做的事 | iShell 如何帮忙 |
| --- | --- |
| 用自然语言部署服务、分析日志或排查故障 | AI 助手调用服务器工具，逐步展示操作和结果，由所选权限模式控制执行 |
| 在服务器项目中使用 Codex、Claude Code | AI 会话、代码差异、测试与日志分屏查看，配色随终端主题适配 |
| 同时管理开发、测试和生产环境 | 文件夹、搜索、标签和颜色组织连接；最多四窗格并排操作 |
| 在多台机器上检查相同信息 | 广播输入配合命令片段，把重复输入发送到选定会话 |
| 上传文件、修改配置并验证服务 | 文件面板与当前终端联动，编辑保存后直接回到 Shell 验证 |
| 排查部署失败、服务卡顿或 GPU 任务 | 独立日志窗口持续跟随输出，监控面板查看资源和进程排行 |
| 访问跳板机后的内网服务 | 最多三级跳板机，以及本地、远程和 SOCKS5 端口转发 |

## 功能亮点

### 1. 内置 AI 服务器助手：从描述目标到执行与验证

- **自然语言操作服务器**：描述部署、巡检或排障任务，助手可执行 Shell、读取和写入文件，并编写执行 Python、Shell 或 Node.js 代码。
- **自选模型服务**：接入 OpenAI 兼容 API，自动读取模型与思考档位，也支持手动填写模型 ID 和 `reasoning_effort`，适配服务端提供的能力。
- **四种操作权限**：仅建议、执行前确认、自动低风险、完全访问。需要确认时，工具卡片展示目标服务器、目录及完整命令或代码。
- **过程与结果可查看**：流式回复与分组工具卡片展示步骤说明、命令、代码、输出、成功/失败状态和退出码；任务可随时请求停止。
- **长任务上下文管理**：按模型声明的上下文窗口自动压缩，也可使用 `/compact` 手动整理；支持 `/new`、`/history`、`/settings` 命令菜单。
- **按服务器保留对话**：历史和工具结果在本机加密保存，可切换、继续或删除对话，并可编辑已发送消息从该处重新开始。模型、思考程度与权限偏好会被记住。
- **远程 AI 编程配套**：在终端运行 Codex、Claude Code 等已安装 CLI，以四窗格并排查看 AI 会话、代码差异、测试和日志；终端背景色报告帮助 CLI 选择深浅配色。

内置助手使用你配置的模型 API，无需安装上述 AI CLI。服务器工具需要远端 Python 3，运行 JavaScript 另需 Node.js。权限规则控制是否执行或确认，实际操作仍使用 SSH 账号权限；停止任务或编辑对话不会撤销已经执行的服务器操作。

### AI 助手快速上手

1. 打开**设置 → AI 助手**，填写 OpenAI 兼容 API 地址与密钥，读取模型元数据并选择默认模型，也可手动补充模型 ID。
2. 连接服务器，点击右上角的 **AI 星光图标**打开侧栏，选择模型、思考程度和操作权限。
3. 输入目标，例如“检查磁盘空间并找出占用较大的目录”，查看工具步骤；遇到确认请求时核对命令，再允许此次或拒绝。
4. 在侧栏查看输出与结论，通过历史记录继续对话；长对话可输入 `/compact`，也可附上希望保留的重点。

| 权限模式 | 执行方式 |
| --- | --- |
| 仅建议 | 提供建议，不执行服务器工具 |
| 执行前确认 | 每次工具调用均需确认 |
| 自动 · 低风险（默认） | 识别为低风险的查询自动执行，修改、代码与未知命令需确认 |
| 完全访问 | 自动执行任务内工具操作，不再逐项确认 |

任务消息、必要的服务器信息与工具输出会发送到配置的模型服务；API 密钥、对话和工具结果在本机加密保存。模型服务需自行配置。详细说明见 [AI 助手使用指南](docs/AI_GUIDE.zh-CN.md)。

### 远程 AI CLI 编程

- **在项目所在的服务器运行 AI CLI**：通过 SSH 进入远程项目目录，启动已安装和配置好的 Codex、Claude Code，让工具在该主机的代码与运行环境中工作。
- **AI 会话与验证并排进行**：最多四窗格，可分别用于 AI 对话、`git diff`、测试命令和服务日志；也可在不同项目目录中分别启动会话，按任务安排标签与窗口。
- **为 AI CLI 适配深浅配色**：终端响应背景色查询，报告当前主题的实际底色，供 Codex、Claude Code 等据此选择配色，改善透明窗口及浅色主题下的可读性。
- **连接修改与验证**：配合文件面板检查小型配置和脚本，在另一窗格运行测试，并用独立日志窗口和状态面板观察运行结果。
- **观察远程 AI 任务**：训练或推理任务可结合日志、进程排行及 GPU/显存指标查看运行情况；GPU 指标需要远端提供兼容支持。

此处的外部 AI CLI 需在远端自行安装、登录并配置模型服务；其会话由用户分别操作。

### 2. 多会话操作：分屏、广播、命令复用

- **交互式终端**：xterm.js 配合真实 PTY 会话，支持标签页重连、复制、拖动排序、拖出新窗口和跨窗口交接。
- **最多四窗格**：左右、上下嵌套分屏，可连接同一台或不同服务器；拖动分隔线调整比例。文件与监控面板跟随当前聚焦的窗格。
- **广播输入**：把输入同步发送到多个选定会话，可逐个勾选目标，适合多机巡检和对照操作。
- **命令片段与历史**：保存常用命令及说明，选择填入终端或自动回车；开启广播后可同步发送到所选会话。历史支持搜索、候选提示和回填。
- **终端内搜索**：支持区分大小写、全字匹配和正则表达式，快速定位当前终端缓冲区中的输出。

### 3. 文件操作：从传输到修改配置

- **两种浏览方式**：树形详情视图与多列视图，可通过路径栏直达目录，支持多选、右键菜单、新建文件夹、重命名和删除。
- **文件与文件夹传输**：支持拖放上传；文件夹可直接下载，或打包为 `.tar.gz` 下载。传输队列显示进度、已传输字节和任务状态，支持停止任务。
- **文件夹替换保护**：遇到远端同名目录时先确认完整替换；上传使用暂存、提交及失败回滚保护流程。
- **远程文本编辑**：内置语法高亮编辑器，可打开并保存不超过 **1 MiB 的 UTF-8 文本文件**，适合修改配置和脚本。
- **目录联动与软链接识别**：从文件菜单让当前终端切换到选中目录；软链接显示专用标识，删除提示区分链接与目标。
- **从终端打开目录**：按住 `⌘`（macOS）或 `Ctrl`（Windows/Linux）点击终端中的 `用户@主机:目录` 提示符，在文件面板定位该目录；目录树随导航展开并滚动到当前位置。

同名文件夹上传采用**完整替换**：不会合并目录，远端独有的内容也会被移除。请在确认框中核对目标。

### 4. 排障工具：独立日志窗口与实时监控

- **实时日志**：从文件右键菜单打开独立窗口，持续跟随远端文件新增内容；支持设置初始行数、暂停跟随、回到底部、清空和重启。关闭窗口会停止对应的远端任务。
- **主机状态**：查看 CPU、内存、Swap、磁盘挂载、负载、进程数和网络上传/下载速度。
- **进程排行**：显示 CPU 和内存占用 Top 5，帮助定位资源消耗较高的进程。
- **GPU 与显存**：远端提供兼容的 `nvidia-smi` 或 Linux DRM 指标时显示相应数据，适合查看远程 GPU 任务的资源占用。
- **通过 SSH 采集**：无需额外安装常驻监控 Agent；具体指标取决于远端系统、命令和权限。

### 5. 内网访问：跳板机与三种转发

服务器资料可以选择另一台已保存的服务器作为跳板，最多串联 **3 级跳板机**，每一级使用各自的账号与密码或私钥。

| 类型 | 用途示例 |
| --- | --- |
| 本地转发 `-L` | 在本机访问仅服务器可达的数据库或管理后台 |
| 远程转发 `-R` | 把服务器上的监听端口转到本机可达的服务 |
| SOCKS5 动态转发 `-D` | 在本机建立经由服务器访问网络的 SOCKS5 代理 |

规则按服务器保存，显示运行状态和失败原因，可在终端连接成功时自动启动。转发适用跳板机设置，独立于终端标签运行，退出应用时停止。

### 6. 连接资产：有组织，也方便迁移

- 用文件夹、标签、备注和主机颜色管理服务器，支持搜索、多选、拖动排序、复制资料、原地重命名及批量删除。
- 支持密码和私钥认证，保存前可测试连接；排序与分组位置在重启后保持。
- 按主机或文件夹导入、导出 iShell JSON/ZIP 配置；设置导出口令时，可一并导出加密后的已保存密码或私钥口令。
- 连接资料、命令历史、片段和转发规则保存在本地，无需注册 iShell 账号即可使用。

### 7. 日常体验：九套主题与应用内更新

- **三种界面语言**：简体中文、繁體中文、English，默认跟随系统语言，也可在设置中切换，立即应用到已打开的窗口。
- **九套主题**：云雾白、暮霭紫、Claude 深色、Claude 浅色、石墨灰、午夜蓝、墨玉绿、曜石黑、象牙白；每套配有独立的 16 色终端调色板。
- **可调外观**：原生透明窗口与玻璃效果、浮动卡片布局、窗口透明度、终端字号、顶部栏自动隐藏。
- **应用内更新**：启动后及每六小时自动检查，也可手动检查或关闭自动检查；更新包通过签名校验后安装并重启。
- **离线更新历史**：在“关于与更新”中按版本展开查看随应用打包的更新记录。

窗口效果因系统而异。

## AI 编程工作流

1. 在远程服务器上准备好项目、开发依赖及 Codex 或 Claude Code，完成该 CLI 所需的登录和模型配置。
2. 用 iShell 连接服务器，进入项目目录，运行 `codex` 或 `claude` 启动对应工具。
3. 将当前标签分屏，在其他窗格中进入同一项目，查看 `git diff`、执行项目的测试命令或跟随日志。
4. 在 AI 会话中提出任务，结合差异、测试和日志检查修改结果；需要调整小型配置时，可使用内置文本编辑器。

| 窗格 | 示例用途 |
| --- | --- |
| AI 会话 | 在项目目录中运行 `codex` 或 `claude` |
| 修改检查 | 用 `git diff` 查看代码改动 |
| 验证 | 执行该项目的测试或构建命令 |
| 运行观察 | 查看服务输出或跟随日志；日志也可单独开窗 |

模型访问遵循所用 CLI 的配置，项目文件位于远端；具体 AI 功能和交互表现取决于 CLI 版本及服务器环境。

### 连接前准备

- **本机**：macOS/Linux 需要可用的 OpenSSH 客户端；Windows 使用内置的纯 Rust `russh` 后端。
- **远端**：需要 SSH 服务和相应访问权限。文件面板的目录列表、上传等操作需要 `python3`；文件夹下载使用 `tar`，压缩下载需要 gzip 支持；日志查看使用 `tail`。
- **监控**：主要面向 Linux/Unix 主机，通过 `/proc`、`ps`、`top`、`df` 等采集数据；部分指标有 macOS/BSD 回退实现。GPU 和显存显示需要远端驱动提供兼容指标。

直接使用安装包无需安装 Node.js 或 Rust。仅启动 SSH 终端不要求远端具备上述全部文件和监控工具。

## 快速开始

1. 安装并启动 iShell，在顶部栏打开**连接管理**。
2. 新建服务器，填写主机、端口和用户名，选择密码或私钥认证；按需配置分组、标签和跳板机。
3. 点击**测试连接**确认可达，保存后双击服务器打开终端。
4. 通过顶部栏打开文件、监控、命令历史、命令片段或端口转发面板。
5. 需要并排工作时，右键标签选择分屏；也可在连接管理中右键另一台服务器，选择**分屏连接**。
6. 需要重复输入时，开启广播并核对目标会话，再输入命令或发送片段。

一个常见流程：**连接服务器 → 上传文件 → 编辑配置 → 在终端验证 → 跟随日志并查看监控**。

| 操作 | macOS | Windows / Linux |

| 向右分屏 | `⌘D` | `Ctrl+Shift+D` |
| 向下分屏 | `⇧⌘D` | `Ctrl+Shift+E` |

## 本地数据与凭据

- **本地存储**：服务器资料、命令历史、片段及转发规则使用应用数据目录中的 SQLite 数据库 `ishell.db`；外观偏好等保存在 WebView 本地存储中。
- **已保存的凭据**：密码或私钥口令以 **AES-256-GCM** 加密后保存在数据库中。加密主密钥位于同一应用数据目录的 `secret.key`，Unix 上设置为 `0600`。当前实现使用本地密钥文件。
- **AI 数据**：模型服务设置与 API 密钥、对话历史及工具结果使用同一本地加密机制保存，不随连接配置导出。使用内置 AI 时，任务消息与必要的服务器信息、工具输出会发送到你配置的模型服务。
- **导出行为**：导出口令留空时只导出连接资料；填写口令时，凭据通过 PBKDF2-HMAC-SHA256 派生密钥并以 AES-256-GCM 加密。连接名称、地址等配置元数据保持可读；私钥文件本身不会打包。
- **主机密钥**：首次连接自动信任并记录主机密钥，后续检查已记录的密钥，拒绝发生变化的密钥。

备份或迁移整个应用数据目录时，应将数据库和主密钥视为同等敏感的数据。命令历史与片段按普通本地数据保存，不适合存放明文口令；跨设备使用私钥时，需要另行准备私钥文件并更新路径。

## 从源码运行

准备 Node.js 22.12+（或更新的 LTS 版本）、Rust stable 和对应平台的 [Tauri 系统依赖](https://v2.tauri.app/start/prerequisites/)，然后运行：

```bash
git clone https://github.com/Raymanhan/ishell.git
cd ishell
npm ci
npm run tauri -- dev
```

仅预览界面可运行 `npm run dev`。浏览器预览使用演示数据和模拟交互，真实 SSH、文件传输和端口转发需要桌面应用。

构建安装包：`npm run tauri -- build`。开发环境、验证命令、架构说明及发布签名配置见 [开发与发布指南](docs/DEVELOPMENT.md)。

- `v1.5.12` AI 助手恢复在工具卡片内审核操作：需要确认时对应卡片自动展开，展示目标服务器、目录和完整命令，可直接拒绝或仅允许此次，不再弹出确认窗口。卡片上不再显示“高风险”等风险等级和原因，风险判断仍决定哪些操作需要确认。修复部分主题下输入 `/` 弹出的命令菜单背景透明、与后面的对话文字重叠的问题。

- `v1.5.11` 优化 AI 助手的交互与输出：使用输入法时按回车确认候选词不再直接发送消息（macOS 上同样有效）；模型、思考程度和权限选择框改为固定宽度，箭头紧跟文字，面板较窄时模型名优先省略。可以编辑自己发出的消息并从这里重新开始，之后的对话和模型上下文随之替换。输入 `/` 会弹出命令菜单（`/compact`、`/new`、`/history`、`/settings`），支持方向键、Tab、回车和 Esc。工具卡片的标题改为模型对这一步用途的简短说明（如“检查磁盘占用”），未提供时显示命令本身；卡片执行时保持折叠，连续的工具调用合并为一组，新步骤从下方滑入。回复文字经过缓冲后匀速显示，不再按网络分块跳动；“正在处理”改为文字滑动高亮。风险等级不再显示在卡片上，需要确认时弹出确认窗口，展示用途、风险原因、目标服务器、目录和完整命令，高风险操作默认聚焦“拒绝”，点击窗口外不会误操作。

- `v1.5.10` 修复 macOS 上打开服务器后终端卡片比相邻卡片高出一截、需打开文件栏才恢复的问题：文件栏和监控栏关闭时，其拖动分隔条不再超出窗口边缘；布局容器若被系统意外滚动会立即归位，终端与侧栏卡片保持对齐。

- `v1.5.9` 改进终端卡片与侧栏的高度约束，统一使用工作区可用空间；窗口重新获得焦点、恢复显示、字体加载、主题变化和侧栏动画结束后，自动同步终端尺寸并重绘。长对话只在消息区域滚动，AI 面板的标题、输入区和底部提示不再被挤压。

- `v1.5.8` 新增多语言界面：支持简体中文、繁體中文和 English，默认跟随系统语言，可在“设置 → 外观”中随时切换，已打开的窗口同步生效；应用及后端返回的错误提示也会翻译，服务器输出和 AI 回复保持原样，日期格式跟随所选语言。AI 上下文自动压缩改为按模型元数据声明的上下文窗口计算（达到窗口的 75% 时压缩，不再限制在 200k），未声明时默认 200k；在 AI 对话中输入 `/compact` 可随时手动压缩，后面可附上需要重点保留的内容。“关于与更新”只显示最近的版本，更早的版本可展开在滚动区域中查看，页面不再被拉长。

- `v1.5.7` 加强 AI 自动模式的权限判断：含通配符、设备文件、疑似凭证路径的命令，以及 `docker inspect`、`systemctl show` 和持续输出的 `tail -f`、`docker stats` 改为需要确认；路径先规范化再判断，自动读取的文件若实际指向凭证会被拒绝。修复长时间推理超过 5 分钟被中断的问题，兼容重复发送工具调用 ID 的网关，不再回传旧轮次的 `reasoning_content`（DeepSeek 会报错）。自动压缩阈值按模型声明的上下文窗口计算（75%，最高 200k），并识别更多上下文超限报错。个别历史记录无法解密时跳过并提示，不再导致 AI 面板不可用；流式回复时不再持续重写历史记录；模型列表接口临时不可用时保存设置不再清空模型；工具输出无变化时降低轮询频率，并自动清理服务器上遗留的临时文件。

- `v1.5.6` AI 工具状态改为“执行成功”“执行失败”“读取成功”等文字，退出码移入展开详情，避免“完成 · 0”的歧义；自动缓存模型、思考程度及手动输入选项，按模型服务记忆，权限按服务器记忆。修改选项后即保存，无需先发送消息；新建对话、重新打开空白对话和重启应用后均可沿用。

- `v1.5.5` 新增 AI 历史记录入口，支持按服务器查看、继续和删除对话；“＋”改为保留历史并新建独立对话，聊天及工具结果在本机加密保存，重启后可恢复查看。执行期间可调整模型、思考程度和权限，修改在下一次发送时生效；切换对话后输出仍归原任务。“关于与更新”新增可展开的历史版本更新内容，标注当前版本并展示待更新版本说明，离线也可阅读随应用附带的历史。

- `v1.5.3` AI 模型与思考档位改由配置服务的元数据接口获取，支持刷新及失效选择重置，并保留手动模型 ID 与思考程度输入，兼容 `/models` 不可用的服务；模型、思考程度和操作权限合并到输入框底部同一行，上下文用量移到下方提示区。

- `v1.5.1` 新增 AI 服务器助手侧栏：OpenAI 兼容模型配置、密钥本机加密、模型/思考程度选择、多轮 Shell 与代码工具调用、输出回传和停止；支持四档权限、保守风险判断与一次性执行确认；上下文达到 200k 估算 tokens 时自动压缩，保留近期工具链与聊天记录。

- `v1.4.6` 进入目录时，左侧目录树自动展开祖先节点并滚动到当前目录；支持按住 Command（macOS）或 Ctrl（Windows/Linux）点击终端提示符，在文件面板打开对应目录，正确解析远端主目录，并支持中文、空格和换行路径。
- `v1.4.5` 下载完成后新增 SVG 图标按钮：文件可打开所在文件夹或使用系统默认应用打开；原样下载的文件夹可直接打开，压缩下载的归档按文件处理；按钮提供悬停提示，打开失败时显示通知。

- `v1.4.3` 修复 Windows 拖出标签时偶发残留且无法消除的悬浮气泡，处理预览窗口延迟创建和鼠标捕获丢失时的清理，并排除将预览气泡误识别为标签接收窗口的情况。
- `v1.4.2` 设置窗口改为左右布局：左侧为“外观”“终端”“关于与更新”三个分类菜单，右侧显示对应设置，切换时窗口大小不变；有新版本时“关于与更新”菜单旁会显示提示圆点。
- `v1.4.1` 设置中新增窗口透明度滑轨，可减少透明主题下窗口背后内容的透出（Windows 上尤其明显），0% 为完全不透明；分屏窗格的标识改为紧贴窗格右上角；修复首次安装时终端字号默认为 11px 而不是 14px 的问题。
- `v1.4.0` 新增跳板机（可多级串联）、端口转发（本地/远程/SOCKS5，后台运行并显示状态）、终端分屏、广播输入、命令片段和终端内搜索；修复浅色主题下终端选中文字看不清，以及在编辑窗口中删除服务器可能删错的问题；新增 Pull Request 自动检查，并拆分大文件便于维护。
- `v1.3.0` 新增应用内自动更新：启动后及每 6 小时在后台检查新版本，发现更新时在右下角提示，可一键下载、安装并重启；设置中新增“关于与更新”，可手动检查或关闭自动检查。更新包经签名校验后才会安装。
- `v1.2.2` 终端会向查询背景色的程序如实报告当前主题的背景，Codex、Claude Code 等 AI 命令行能自动选用匹配的浅色或深色样式，浅色主题下输入文字不再看不见。

- `v1.1.19` 扩展实时监控面板，新增 GPU/显存指标，并加入按 CPU 与内存排序的实时 Top 5 进程排行。
