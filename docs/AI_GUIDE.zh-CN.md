# AI 服务器助手

[返回 README](../README.zh-CN.md) · [English](AI_GUIDE.md)

1. 打开 **设置 → AI 助手**，填写 OpenAI 兼容 API 地址和密钥。点击“读取 / 刷新元数据”从服务的 `/models` 接口获取模型与支持的思考档位，选择默认模型后保存；未列出的模型可在“手动补充模型 ID”中添加。密钥使用现有本机密钥加密存入 SQLite，不写入浏览器存储或连接导出。
2. 连接服务器后，点击右上角的 **AI 星光图标** 打开侧栏。模型、思考程度和操作权限位于输入框底部同一行。模型与思考档位由服务元数据决定，兼容 `supported_reasoning_efforts`、Codex `supported_reasoning_levels` 等声明；没有声明具体档位时默认使用服务默认值，也可选择“手动输入…”指定模型 ID 或 `reasoning_effort`。手动模型不依赖 `/models` 可用；手动输入的值会按原样发送。打开应用、保存设置或点击侧栏的刷新图标时会重新读取元数据，发送请求前会校验模型与档位。
3. 点击侧栏顶部的 **历史记录图标** 查看、切换或删除当前服务器的对话；“＋”会新建独立对话，保留原记录。执行中的任务可从历史中切回查看或停止，需停止后才能删除。模型、思考程度和权限在执行期间仍可修改，修改用于下一次发送；当前任务沿用启动时的设置。
4. 描述部署、排查或运维目标。AI 可使用 Shell、读取/写入文件，以及编写并执行 Python、Shell 或 Node.js 代码；每一步显示命令、代码、输出及“执行成功”“执行失败”等状态，展开详情可查看真实退出码。工具需要远端 Python 3，JavaScript 另需 Node.js；非交互提权使用服务器已有的 `sudo -n` 权限。

模型、思考程度及手动输入选项会在调整时缓存到本机，按模型服务分别记忆；权限按服务器记忆。新建对话、重新打开空白对话或重启应用后可沿用上次选择，已有历史对话和未发送的草稿保留各自的配置。

**权限**可在输入框下方选择，也可在设置中指定新对话的默认值：

| 模式 | 行为 |
| --- | --- |
| 仅建议 | 不执行服务器工具，只提供建议 |
| 执行前确认 | 每次工具调用均需用户确认 |
| 自动 · 低风险（默认） | 只读操作（查看文件、日志、状态、列表等）自动执行；写入文件、修改服务器、安装软件、运行脚本或代码、读取凭证文件及无法确认是否只读的命令需确认 |
| 完全访问 | 自动执行任务内的工具操作，不再逐项确认 |

需要确认时对应的工具卡片会展开，展示目标服务器、目录与完整命令/代码，可拒绝或仅允许此次；风险判断只决定是否需要确认，不在卡片上显示。工具卡片默认折叠，标题是模型对这一步用途的简短说明，连续的工具调用合并为一组。判断采用保守规则，不是隔离沙箱；实际可用权限仍受 SSH 用户权限限制。

对话绑定发起任务的终端连接，切换标签不会把任务转到另一台服务器；关闭侧栏后仍可打开继续查看，关闭或重连终端会请求停止任务。可随时停止，已完成的操作不会回滚。每个工具默认超时 120 秒、最长 1800 秒，输出保留有限尾部并标注截断。

**上下文上限由模型元数据声明的窗口决定**，估算用量达到窗口的 75% 时自动压缩；元数据未声明窗口时，以估算上下文达到 200k tokens 为自动压缩阈值：达到阈值时生成历史摘要，保留原始任务、近期完整工具调用、关键结果与未完成事项；聊天记录仍可查看。压缩失败或取消时保留原上下文。模型提前报告上下文超限时也会尝试压缩一次。在对话中输入 `/compact` 可随时手动压缩，后面附上的文字（例如 `/compact 保留 nginx 的修改`）会告诉摘要需要重点保留的内容。在输入框中输入 `/` 会列出可用命令（`/compact`、`/new`、`/history`、`/settings`），可用方向键、Tab 和回车选择。悬停在自己发出的消息上可编辑并从这里重新开始：之后的对话与模型上下文会被替换，已在服务器上执行的操作不会撤销；已被压缩进摘要的消息无法编辑。自动模式会把命令按管道、`;`、`&&`、子命令等拆开逐段判断：只读的命令（含管道组合、`2>/dev/null` 等）自动执行；重定向写文件、`sed -i`、安装/卸载软件、启停服务、`docker run`/`kubectl apply`/`git pull` 等写操作，以及运行脚本或解释器代码、无法确认是否只读的命令需确认；`tail -f`、`docker stats` 等持续输出的命令也会先确认，建议改用一次性查询。读取疑似密钥或凭证文件（如 `~/.ssh`、`.env`、`*.key`），或在主目录、隐藏目录使用通配符时也需确认；自动执行的 `read_file` 若实际指向凭证文件会被拒绝。对话和工具结果在本机加密保存，重启后可从历史记录打开；未完成的任务不会自动恢复执行。任务消息和必要的服务器信息、工具输出会发送到配置的模型服务。

在 **设置 → 关于与更新 → 版本更新历史** 中可按版本展开查看更新内容，当前版本默认展开；检查到新版本时也会展示其更新说明。历史随应用打包，离线可读，并与发布使用的更新记录保持同步。
